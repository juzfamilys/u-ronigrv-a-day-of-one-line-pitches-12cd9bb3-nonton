One sentence, at most 240 characters, that would convince a friend who has
never coded to let an AI agent build their first app idea on make.fun.
`main.py` writes that sentence — and nothing else — to `entry.txt`.

> Tell an AI agent your app idea in plain words and it builds the whole thing for you — you only pay the winner, so your first idea costs nothing to try.

## Run it

```sh
python3 main.py
```

This writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). Pure Python standard library, no dependencies.
